# dashcam-bingo

Web-based bingo cards for watching dashcam videos.

## Run locally (no dependencies)

Open `/home/runner/work/dashcam-bingo/dashcam-bingo/index.html` in any modern browser.

## Deploy to GitHub Pages

This project is a static site and requires no build step or package dependencies.

1. In GitHub, go to **Settings → Pages**.
2. Under **Build and deployment**, set **Source** to **GitHub Actions**.
3. Push to `main` (or run the **Deploy static site to GitHub Pages** workflow manually).

The workflow in `/home/runner/work/dashcam-bingo/dashcam-bingo/.github/workflows/deploy-pages.yml` will publish the site.
